# Jk Algo Hub

Trading terminal web app starter.

## Current milestone
- Exactly 4 main pages: Watchlist, Charts, Algo, P&L
- Paper/Real mode selector
- ₹10,000 default editable paper capital
- Persistent local state for key paper-trading settings
- Watchlist to chart navigation
- 1/2/4/6/8 chart layouts
- 9/26 EMA strategy controls
- Paper BUY/SELL simulation
- Position close and P&L tabs
- Mobile responsive dark trading UI

## Run
npm install
npm run dev

## Production integrations
Live market-data WebSockets, broker execution, secure backend credential storage and full Pine Script execution must be connected to real documented providers; they are intentionally not faked in this milestone.
